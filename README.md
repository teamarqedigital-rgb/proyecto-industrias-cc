# Industrias CC

Sitio web estático de Industrias CC, creado con HTML, CSS y JavaScript.

## Páginas

- Inicio y catálogo de productos
- Historia de la familia
- Galería de prendas y estampados
- Cómo comprar, preguntas frecuentes y contacto

## Ejecución local

Abre la carpeta con un servidor web estático y visita la dirección local que este indique. Servir el sitio por HTTP permite que el navegador cargue correctamente los módulos de Firebase.

## Publicación en GitHub Pages

Cada cambio que se suba a la rama `main` se publica automáticamente con GitHub Actions. La URL del sitio es `https://teamarqedigital-rgb.github.io/proyecto-industrias-cc/`.

## Datos y servicios externos

El catálogo incluye productos locales de respaldo y puede consultar Firebase. Para habilitar la sincronización, revisa la configuración de Firebase y las reglas de lectura de Firestore; no publiques credenciales privadas ni archivos `.env`.
